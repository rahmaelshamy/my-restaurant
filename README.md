# My Restaurant Website

A modern and responsive restaurant website developed using HTML, CSS, Bootstrap, and JavaScript.

## Live Demo
https://rahmaelshamy.github.io/my-restaurant/

## Features
- Responsive design using Bootstrap
- Interactive like/heart buttons
- Menu section with food items
- Contact form with validation
- Custom phone and email validation

## Technologies Used
- HTML5
- CSS3
- Bootstrap 5
- JavaScript (jQuery)

##  Project Structure
- index.html → Home page
- about.html → About page
- contact.html → Contact form
- style.css → Styling
- script.js → Functionality
- images/ → All images
